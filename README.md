# Bramwell & Bell

**The future of work. Properly managed.**

A fictional British technology company, founded in 2026. Corporate satire in the style of a completely serious business website.

## V1

- Static, responsive single-page website
- HTML, CSS and a tiny amount of JavaScript
- No dependencies, API keys, build tools or database
- Fictional CEO Graham P. Scale
- Fictional HQ in Peterborough, Cambridgeshire (no real office or premises claimed)
- Clear fiction/satire disclosure in the footer

## Run

Open `index.html` in a browser.

## Deploy to Vercel

1. Import `simplybenuk/bramwellbell` as a new project.
2. Framework preset: **Other**. No build command.
3. Add the purchased domain `bramwellbell.company` in Project → Settings → Domains.
4. Follow Vercel's DNS instructions.

## Before going live

- Replace the placeholder `enquiries@bramwellbell.company` link with a real working mailbox or contact method.
- Confirm the domain's DNS and SSL certificate.
- Add product portfolio links when the first demo launches.
- Keep the fiction disclosure; the company and its headquarters are fictional.

## Creative direction

The company is a brand-new AI startup run by people with an old-fashioned British middle-management mindset. The humour comes from the contrast between genuinely modern software and absurdly bureaucratic leadership. Nobody at Bramwell & Bell believes they're in a comedy.
